En Sculpturillo podés crear tu propio contenido y compartirlo por el Steam Workshop: otros se suscriben, lo descargan y lo usan en sus partidas. Hoy podés crear bancos de palabras; los mapas llegarán pronto.

In Sculpturillo you can create your own content and share it through the Steam Workshop: others subscribe, download it, and use it in their games. Today you can make word banks; maps are coming soon.

Bancos de palabrasWord banks tag: WordBank

Un banco es un archivo .csv (texto) con una palabra por línea. Lo abrís con el Bloc de notas o Excel. No necesitás Unreal.

A word bank is a .csv (text) file with one word per line. Open it with Notepad or Excel. No Unreal needed.

Formato: Palabra,Categoría,Dificultad

Format: Word,Category,Difficulty

  • Palabra: lo que hay que esculpir/adivinar.
  • Word: what players sculpt/guess.
  • Categoría: texto libre (ej: Películas, Animales).
  • Category: free text (e.g. Movies, Animals).
  • Dificultad: 1 fácil, 2 media, 3 difícil.
  • Difficulty: 1 easy, 2 medium, 3 hard.

Ejemplo (animales.csv):

Example (animals.csv):

Palabra,Categoria,Dificultad
Perro,Animales,1
Elefante,Animales,2
Pulpo,Animales,3
Guardalo como UTF-8Save it as UTF-8 para que los acentos y la ñ se vean bien. so accents and special characters display correctly.

Cómo publicarlo

How to publish it

  1. Abrí el juego → Workshop (menú principal).
  2. Open the game → Workshop (main menu).
  3. Pestaña Bancos de palabras → botón Publicar CSV.
  4. Word banks tab → Publish CSV button.
  5. Elegí tu archivo .csv → se sube a tu Workshop.
  6. Pick your .csv file → it uploads to your Workshop.
  7. La primera vez, Steam te pide aceptar el acuerdo del Workshop.
  8. The first time, Steam asks you to accept the Workshop agreement.

Cómo usarlo en una partida

How to use it in a game

  1. Suscribite a un banco desde el Workshop (botón Añadir).
  2. Subscribe to a bank from the Workshop (Add button).
  3. Creá una partida → Game Settings → Biblioteca.
  4. Host a game → Game Settings → Library.
  5. Pestaña Palabras → Usar el banco que quieras.
  6. Words tab → Use the bank you want.
