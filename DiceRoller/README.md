# 🎲 Tirar Dados

App sencilla para tirar **dos dados al azar**.

## Cómo usarla

Abre el archivo `dados.html` con doble clic en cualquier navegador (Chrome, Edge, Firefox, Safari). No necesita instalación ni internet.

## Qué hace

- Tira dos dados con una animación de sacudida.
- Muestra el valor de cada dado y la **suma total**.
- Avisa cuando salen **dobles** (los dos dados con el mismo número).

Cada dado da un número aleatorio del 1 al 6 usando `Math.random()`.
